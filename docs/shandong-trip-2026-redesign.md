# 山海同行 · 山东家庭随行手册

2026-09-08 至 09-13，青岛—崂山—泰安—济南。基于用户提供的 2026-09-06 交接文档及原仓库 master `a2b2a5465e2e768a56e55c1f0b1b06798ea85a10` 的七个 HTML 页面改版。

## 维护

- `content.json`：六天行程、高铁、酒店、餐厅、点位、路段与提醒。
- `scripts/build.py`：用 Python 标准库生成 `dist/` 中的八个页面（总览、六日、图片来源），并按内容生成离线缓存版本。
- `dist/assets/trip.css`、`trip.js`：共用样式与渐进增强交互。
- `dist/sw.js`：当前行程作用域内的离线缓存。全套资源准备成功后才报告离线可用，不清理博客等无关缓存。旧窗口关闭后，新版本方可完整接管。
- `npm run dev`：仅供本地检查的静态服务器，无第三方依赖；`/__qa` 为320/390px视口检查页，`?__clipboard=deny`仅在开发服务器上模拟复制受限。开发服务器不会进入公开静态输出。
- `python scripts/build.py`：重新生成页面；`node scripts/check-clock.cjs`：检查北京时间与时间边界。

原 GitHub Pages 的发布路径保持 `source/shandong-trip-2026/`，将 `dist/` 内容同步到该目录。原 Hexo `skip_render: shandong-trip-2026/**` 保持不变。
